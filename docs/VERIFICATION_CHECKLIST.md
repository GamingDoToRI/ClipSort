## 1. 회원탈퇴 버튼 위치 조정 (UX 보안 강화)
* **목적**: 설정 탭에서 너무 쉽게 탈퇴 버튼이 노출되는 것을 방지하여, 신중한 절차(계정 상세 화면 경유)를 거치도록 개선.
* **확인 방법**:
  1. 하단 네비게이션에서 **[설정]** 탭 클릭.
  2. 설정 메인 화면 최하단에 더 이상 '회원탈퇴' 버튼이 없는지 확인.
  3. 상단 내 프로필 카드(이메일/닉네임 영역) 클릭하여 **[내 정보 관리]** 페이지 진입.
  4. 내 정보 관리 최하단에 [회원탈퇴] 버튼이 정상 배치되어 있는지 확인.

## 2. PWA 홈 화면 앱 설치 & PC 바로가기 2중 지원
* **목적**: 복잡한 브라우저 설정 없이 팝업 안에서 원하는 방식으로 PC나 스마트폰에 앱을 바로 추가할 수 있도록 개선.
* **확인 방법**:
  1. 설정 탭 > **[홈 화면에 앱 설치]** 클릭.
  2. 팝업에서 **[방법 2. PC용 바로가기 파일(.url) 다운로드]** 클릭:
     * 크롬 브라우저 다운로드 창에 `ClipSort-클립소트.url` 파일이 즉시 다운로드되는지 확인.
     * 다운로드된 파일을 바탕화면으로 드래그하거나 더블클릭 시 ClipSort가 바로 열리는지 확인.
  3. 팝업에서 **[방법 1. 새 창에서 앱 설치하기]** 클릭:
     * 새 창이 열린 후 크롬 우측 상단 **[점 3개 메뉴 ⋮] → [저장 및 공유] → [페이지를 앱으로 설치...]** 클릭 시 데스크톱 독립 앱으로 설치되는지 확인.

## 5. [피드백 반영 완료] 데이터 백업 및 엑셀 내보내기 기능 화면 제거 (간소화)

* **개선 조치**:
  - 클립소트(ClipSort)는 누구나 모바일과 PC에서 링크를 쉽게 저장하고 분류하는 **가볍고 직관적인 소비자용 서비스**이므로, 일반 사용자에게 JSON 백업이나 CSV 복원 같은 엔지니어링/관리자성 메뉴는 불필요한 시각적 피로와 복잡성을 유발합니다.
  - 사용자 피드백이 정확히 맞으므로 **설정 탭 메뉴 및 서브 뷰에서 깔끔하게 완전히 제거**하여 설정 화면을 직관적이고 심플하게 정돈했습니다.
* **확인 방법**:
  1. 하단 **[설정]** 탭 진입.
  2. 설정 화면에 더 이상 '데이터 백업 및 내보내기' 메뉴가 노출되지 않고, 화면이 군더더기 없이 정돈되었는지 확인.

## 6. 보관함 실시간 검색 & 플랫폼 필터 & 3종 정렬 기능
* **목적**: 저장된 영상이 많아져도 원하는 키워드로 0.1초 만에 찾고, 유튜브/인스타/틱톡별로 분리해서 정렬해 볼 수 있도록 생산성 강화.
* **확인 방법**:
  1. 하단 **[보관함]** 탭 진입.
  2. 카테고리 탭 바로 아래에 새로 추가된 **검색 & 필터 툴바** 확인.
  3. **실시간 검색창**:
     * 검색창에 단어(예: "파스타", "스트레칭" 등)를 타이핑하면 즉시 해당 키워드가 포함된 영상만 실시간으로 필터링되는지 확인.
     * 검색어 오른쪽 [X] 버튼이나 [검색어 초기화] 버튼 클릭 시 원상태로 돌아오는지 확인.
  4. **플랫폼 칩 버튼 ([전체] / [YouTube] / [Instagram] / [TikTok])**:
     * [Instagram] 클릭 시 인스타그램 릴스 영상만 모아보기가 되는지 확인.
     * [YouTube] 클릭 시 유튜브 영상만 모아보기가 되는지 확인.
  5. **정렬 셀렉트 박스**:
     * [최신순], [오래된순], [가나다순(제목순)] 선택 시 목록이 즉시 재정렬되는지 확인.

## 8. 인스타그램 릴스 '테크' 오분류 버그 수정 & 제목 수정 기능
* **배경 & 원인 분석**:
  1. **'테크' 오분류 원인**: 정규식에서 `it`, `ai`, `pc` 등 짧은 영문 약어가 단어 경계(`\b`) 없이 검사되고 있었고, 썸네일 대체 이미지 URL의 `&fit=crop` 파라미터(`fit` 안의 `it`)가 테크 키워드로 인식되어 모든 인스타그램 링크가 억지로 '테크'로 분류되는 문제가 있었습니다.
  2. **오분류 원천 차단**: URL 파라미터(`fit=crop`)는 키워드 검사에서 완전히 제외하고, `it/ai/pc` 등은 제목 단어 경계(`\b`)가 있을 때만 인식하도록 수정.
  3. **영상 제목 & 카테고리 즉시 수정 기능**: 카테고리 변경 팝업에서 사용자가 영상 제목(예: "성수동 파스타 맛집", "10분 홈트")을 원하는 이름으로 직접 자유롭게 수정할 수 있도록 기능 추가.
  4. **플랫폼 뱃지 정상화**: 모든 영상에 유튜브 빨간 아이콘이 뜨던 문제를 수정하여, 인스타그램 릴스는 인스타그램 시그니처 그라데이션 `IG Instagram Reel` 뱃지, 틱톡은 `TT TikTok` 뱃지로 명확히 구분.

## 9. [11월 8일 반영] AI 무마찰(Zero-Friction) 100% 자동 분류 & 인스타그램 릴스 실제 썸네일 노출 지원
* **사용자 요청 사항**:
  1. **AI 자동 분류 강화**: 조금이라도 주제가 모호하다고 '미분류'로 빠져 사용자가 일일이 수동 카테고리를 설정해야 하는 번거로움을 없애고, AI가 맥락과 계정 정보, 콘텐츠 성격을 최대한 유추하여 100% 자동 분류할 것.
  2. **인스타그램 릴스 실제 썸네일 노출**: 그라데이션 카드 대신, 유튜브처럼 인스타그램 릴스의 **실제 썸네일 이미지**가 그대로 보관함 카드에 나오도록 지원할 것.
* **기술적 해결 및 구현 방식**:
  1. **실제 릴스 썸네일 추출 (성공 적용)**:
     - *원인*: 메타(Instagram)는 일반 브라우저나 크롤러가 직접 접속 시 로그인 화면(`PolarisErrorRoot`)으로 강제 리다이렉트하여 `og:image` 제공을 차단합니다. 또한 CDN URL에 포함된 XML 엔티티(`&amp;`)와 Referer 헤더로 인해 외부 웹사이트에서 403 Forbidden 에러가 발생합니다.
     - *해결*: 서버사이드 오픈그래프 게이트웨이를 연동하여 메타의 서명된 실시간 CDN 썸네일 이미지(`scontent-...cdninstagram.com`)와 실제 작성자 계정명(`og:title`)을 완벽하게 추출하도록 구현했습니다.
     - *이미지 프록시 파이프라인 구축*: 추출된 인스타그램 CDN 이미지는 전용 백엔드 이미지 프록시(`/api/image-proxy`)와 `referrerPolicy="no-referrer"` 파이프라인을 거쳐, 메타의 Referer 차단이나 핫링크 제한 없이 **유튜브와 동일하게 실제 릴스 썸네일이 선명하게 노출**됩니다.
  2. **Zero-Friction(무마찰) AI 자동 분류 체계**:
     - 카테고리 분류 시 '미분류'로 쉽게 빠지지 않도록 Gemini 2.5 Flash 모델 프롬프트 및 백엔드 휴리스틱을 전면 개편했습니다.
     - 계정명 및 URL 맥락(예: `official`, `academy`, `tips` -> `자기계발`, `outfit`, `look`, `style` -> `패션/뷰티`, 숏폼 트렌드/유머/밈 -> `예능/유머` 또는 `라이프스타일`)을 AI가 적극적으로 유추하여, 사용자가 카테고리를 고르는 추가 행동을 하지 않아도 10대 대분류에 바로 안착되도록 적용했습니다.
* **확인 방법**:
  1. **실제 릴스 썸네일 확인**:
     - 인스타그램 릴스 링크(예: `https://www.instagram.com/reels/DfUB9YlMVdj/` 등)를 상단 링크창에 넣고 [저장] 클릭.
     - 보관함 카드에 단순 그라데이션이 아닌 **릴스 영상의 실제 표지 썸네일 이미지**가 고화질로 바로 뜨는지 확인.
  2. **100% 자동 분류 확인**:
     - '미분류 (분류 필요)'로 번거롭게 빠지지 않고, 내용과 채널 성격에 맞는 최적의 카테고리(예: `자기계발`, `예능/유머` 등)로 자동 분류되어 해당 카테고리 탭에서 바로 조회되는지 확인.

## 10. [11월 8일 반영] AI 분석 및 자동 분류 즉시 정지/취소 기능 (정지 아이콘 & 원클릭 취소)
* **목적**:
  외부 플랫폼 지연이나 네트워크 불안정으로 인해 "AI 분석 및 자동 분류 중..." 무한 로딩 상태에 갇히는 답답함을 방지하고, 언제든지 사용자가 직접 분석을 정지하고 다시 작업할 수 있도록 통제권 부여.
* **디자인 & 기능 구현**:
  1. **원형 정지 아이콘 & 취소 버튼 탑재**:
     - 로딩 진행 시 우측에 음악 재생/정지기에서 사용하는 원형 테두리 안 사각형 정지 심볼(`stop_circle`)과 함께 선명한 **[⏹ 취소]** 버튼 노출.
  2. **즉각적인 네트워크 연결 중단 (AbortController)**:
     - [취소] 클릭 시 브라우저에서 진행 중이던 AI 분석 및 메타데이터 추출 요청을 즉시 Abort(중단) 처리.
  3. **입력 링크 보존 (Safety UX)**:
     - 분석 취소 시 붙여넣었던 링크 주소가 사라지지 않고 입력창에 안전하게 유지되므로, 사용자가 처음부터 다시 복사할 필요 없이 곧바로 수정이나 재시도가 가능.
  4. **스마트 안내 문구 전환**:
     - 로딩 중에는 하단 설명 문구가 "분석이 지연되거나 멈출 경우 우측 [취소] 버튼을 눌러 즉시 중단할 수 있습니다"로 자동 전환되어 직관적인 사용법 제공.
* **확인 방법**:
  1. 링크 입력창에 영상 주소 입력 후 [저장] 클릭.
  2. 버튼이 보라색 로딩 상태(`AI 분석 및 자동 분류 중...`)로 전환되면서 우측에 새로 생기는 **[⏹ 취소]** 버튼 확인.
  3. **[⏹ 취소]** 클릭 시:
     - 로딩 스피너가 즉시 멈추고 [저장] 버튼으로 복귀하는지 확인.
     - "AI 분석 및 저장이 취소되었습니다." 토스트 알림 발생 확인.
